# 每日高考英语时文阅读 | Daily English Reading

📚 为高三学生每天自动生成一篇英文时文阅读材料，帮助学生备考高考英语。

## 项目特色

- **时效性强**：精选近3天国际权威媒体报道，紧贴时事热点
- **结构完整**：每篇文章包含摘要、词汇、例句、长难句、写作素材、讨论问题
- **难度适中**：词汇量800-1000词，难度适合高三学生备考
- **写作导向**：提供地道表达和写作素材，助力高考英语作文
- **每日更新**：坚持每日更新，养成良好阅读习惯

## 文章结构

每篇文章包含以下10个完整部分：

1. 返回按钮
2. 文章头部（标题、日期、分类）
3. 摘要（中文100字）
4. 正文（800-1000词）
5. 词汇表（15个核心词汇表格）
6. 例句（8个地道例句）
7. 长难句（3-4个框格式解析）
8. 写作素材（6个地道表达表格）
9. 讨论问题（3个深度思考题）
10. 页脚
